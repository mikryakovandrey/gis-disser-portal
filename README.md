# AgroSphere GIS Portal

MVP web application for demonstrating a precision farming GIS portal with:

- Next.js
- React
- TypeScript
- Tailwind CSS
- Leaflet
- Recharts

## Run locally

```bash
npm install
npm run dev
```

Open `http://localhost:3000`.

## Pages

- `/` dashboard with KPI cards and latest recommendations
- `/gis` GIS workspace with filters, interactive map, field intelligence panel, and analytics charts
